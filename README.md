# Unclick

**Unclick your cloud: turn ClickOps into OpenTofu / Terraform code.**

Unclick finds the resources that already exist in your cloud accounts and SaaS tools and writes them out as infrastructure-as-code, so you can manage them with OpenTofu or Terraform from now on.

> **Status: work in progress.** Unclick is the continuation of [Terraformer](https://github.com/GoogleCloudPlatform/terraformer), which was archived on March 16, 2026. It is being rebuilt, and the command line interface may change before the first release.

## What is changing compared to Terraformer

Planned for the first release:

- **Current providers.** Support for plugin protocol v5 and v6, so providers built on the new plugin framework work again.
- **OpenTofu and Terraform.** Both are supported, including provider caches from `registry.opentofu.org`.
- **Configuration generated by the provider itself.** Unclick discovers resources and emits `import` blocks, then OpenTofu or Terraform generates the configuration. No outdated attributes, no hand-written state files.
- **A focused set of providers.** The most-used Terraformer providers are kept and updated, and rarely used ones are dropped.

Until then, the original documentation is in [docs/upstream-README.md](docs/upstream-README.md) and in the per-provider pages in [docs/](docs).
